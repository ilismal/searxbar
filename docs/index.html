Cloudflare Access

¿Tu instancia está detrás de Access?
Sin problema.

SearxBar sigue el flujo de login dentro de la app y te devuelve exactamente donde estabas.

PASO 1

Buscas

Si no hay sesión o ha caducado, Cloudflare redirige a <equipo>.cloudflareaccess.com.

PASO 2

Inicias sesión

Con tu proveedor de identidad, sin salir de la app. Compatible con el login OAuth de Google.

PASO 3

Vuelves a tus resultados

Access fija la cookie CF_Authorization y la búsqueda original continúa.

Empezar

Instálala en un minuto

Recomendamos Obtainium para recibir las actualizaciones directamente desde las releases de GitHub.

  1. Instálala con Obtainium o descarga el APK de la última release (tendrás que permitir orígenes desconocidos).
  2. Abre la app y pulsa Introducir URL, o Elegir de searx.space para usar una instancia pública.
  3. Escribe en la barra y pulsa buscar.
  4. Opcional: mantén pulsada la pantalla de inicio → Widgets → SearxBar.
$ git clone https://github.com/ilismal/searxbar.git
$ cd searxbar
$ ./gradlew assembleDebug

¿Prefieres compilarla tú? Necesitas Android Studio (o JDK 17–22 + Android SDK 35). Los detalles de la release firmada están en el README.

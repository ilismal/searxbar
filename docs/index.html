SearxBar

App y widget de Android para buscar en tu instancia de SearXNG. Material 3, sugerencias mientras escribes y compatible con instancias protegidas por Cloudflare Access.

Descargar APK Código en GitHub

Requiere Android 8.0 o superior · Licencia WTFPL

Características

Tu instancia, tus reglas

Introduce la URL de cualquier instancia de SearXNG, también http:// en red local.

Instancias públicas

Elige una del listado de searx.space, ordenadas por velocidad, con disponibilidad, nota TLS y versión.

Cloudflare Access

Si la instancia está protegida, la app te lleva al login de Access (Google, GitHub, Okta, PIN por correo…) y vuelve a la búsqueda que estabas haciendo.

Sugerencias mientras escribes

A través de la propia instancia: DuckDuckGo por defecto, también Google, Qwant o el proveedor configurado.

Widget

Barra de búsqueda 4×1 redimensionable para la pantalla de inicio, con colores Material You.

Material 3

Colores dinámicos en Android 12+ y modo oscuro.

Abre como prefieras

Resultados en una pestaña integrada, en el navegador o dentro de la app. Mantén pulsado un enlace para abrirlo, copiarlo o compartirlo.

Integrada en el sistema

Compartir → SearxBar, Buscar con SearxBar al seleccionar texto y búsquedas web del sistema.

Instalación

  1. Instálala con Obtainium para recibir las actualizaciones directamente desde GitHub, o descarga el APK de la última release (tendrás que permitir orígenes desconocidos).
  2. Abre la app y pulsa Introducir URL, o Elegir de searx.space para usar una instancia pública.
  3. Opcional: mantén pulsada la pantalla de inicio → Widgets → SearxBar para añadir la barra de búsqueda.

Compilar

Requisitos: Android Studio (o JDK 17–22 + Android SDK 35).

git clone https://github.com/ilismal/searxbar.git
cd searxbar
./gradlew assembleDebug
